# IIH Home Tuitions

A single-page, responsive, parent-friendly landing site for IIH Home Tuitions
(Class 7 to 10, home and online, free demo).

## Stack
- Static HTML / CSS / JS (no build step)
- Google Fonts (Plus Jakarta Sans, Fraunces)
- Inline SVG icon sprite

## Local preview
Open `index.html` in any modern browser.

## Deploy
This repository is deployed on Vercel. Every push to `main` triggers an
automatic redeploy.
